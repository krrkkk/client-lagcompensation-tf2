# projectile lab

экспериментальная предикция снарядов для tf2. клиент + сервер 0.4.1, by avxgroup.

снаряд появляется локально, сервер подтверждает результат. на свободном участке
компенсируется до 100 мс полёта. урон, хп, хитсаунды и убийства считает сервер.

## установка

1. закрой tf2. закинь папку `tf` из windows-архива в `Team Fortress 2` с заменой старых файлов.
2. запусти игру с `-insecure -console`.
3. введи `exec projectile_lab`.

подключение: `185.137.93.189:27018`. арена выбирается через `!add`.
dll загружается через `plugin_load`, без инжектора и автозапуска. sourcemod нужен только серверу.

- `cl_projectile_prediction 0` — выключить.
- `cl_projectile_prediction 1` — включить.
- `cl_projectile_prediction` — посмотреть статус.

для обычной игры закрой tf2 и убери `-insecure`.

## фиксы 0.4.1

- остальные модели снарядов тоже повёрнуты на 90 градусов влево.
- пайпы, липучки и другие физические снаряды больше не теряют скорость при компенсации.
- серверные обновления берут настоящую скорость физического объекта, в том числе после отскоков.

## что есть

- локальные ракеты и пламя без ожидания сервера, исправленные границы модели и плавное подтверждение.
- варианты ракетниц, пайпы, липучки, флаеры, стрелы, лечебные и ремонтные болты, энергетические снаряды, банки, молоко, газ, тесаки, мячи и крюк.
- гравитация, скорость от заряда, базовые отскоки, приклеивание и обновления позиции с сервера.
- предикция толчка рокетджампа, повтор команд и серверная коррекция.
- проверка карты и недавних позиций игроков/дверей перед ускоренным расчётом полёта.

это тестовая сборка. отскоки гранат, разброс и нестандартные атрибуты могут расходиться с сервером.
стики- и флаерджампы, заклинания, ракеты турели и редкие снаряды пока работают штатно; полная локальная предикция для них не закончена.
ранних цифр урона и выдуманных хитсаундов нет. подтверждённый урон показывает обычный худ tf2.

## сервер

установи [metamod](https://www.sourcemm.net/) и [sourcemod](https://www.sourcemod.net/),
закинь `tf` из серверного архива в папку сервера. запуск: `-insecure -port 27018`.
в конфиг добавь `sm_rp_max_advance 0.100` и `sm_rp_advance 1`.
статус в серверной консоли: `sm_rp_status`.

готовый клиент включается только на адресе стенда или `127.0.0.1:27018`.
для другого сервера поменяй адрес в `allowedServer()` и `config/projectile_lab.cfg`, затем пересобери dll.
серверный плагин не загрузится на другом порту или без `-insecure`.

## сборка

нужны python 3, g++, clang 19+, lld, Microsoft CRT/Windows SDK через xwin
и [sdk Valve](https://github.com/ValveSoftware/source-sdk-2013/tree/be57e3d01ac7d7aa6a2cacbfef187c0b46616db0).
используй указанный коммит. обязательны Microsoft C++ ABI и RTTI.

```sh
python3 tools/build.py --client-only --windows-sdk /путь/к/xwin --source-sdk /путь/к/source-sdk-2013
```

для сервера убери `--client-only` и добавь `--sdk /путь/к/sourcemod/scripting`.
сборка будет в `.dserv/tmp/projectile-prediction/build`. готовые профили оружия уже включены.

обновить профили вручную:

```sh
python3 tools/weapons.py --schema /путь/к/tf/scripts/items/items_game.txt
```

## логи

`tf/logs/projectile_prediction.log` — загрузка, выстрелы и время подтверждений.
`tf/logs/projectile_prediction_exceptions.log` — ошибки при вылете, которые увидел модуль.
