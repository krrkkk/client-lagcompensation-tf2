# dependencies

- [Valve Source SDK 2013](https://github.com/ValveSoftware/source-sdk-2013), commit `be57e3d01ac7d7aa6a2cacbfef187c0b46616db0`. the build uses its interfaces and headers. its own license applies to SDK material.
- [SourceMod](https://github.com/alliedmodders/sourcemod) and [MetaMod:Source](https://github.com/alliedmodders/metamod-source), under their respective licenses.
- [LLVM/clang](https://llvm.org/) and [xwin](https://github.com/Jake-Shadle/xwin) provide the build toolchain. Microsoft's runtime and SDK terms apply to Microsoft files.

SDKs, game models, textures, metamod and sourcemod are not bundled. visuals use files from the installed copy of tf2. this is an unofficial project, not affiliated with Valve.
